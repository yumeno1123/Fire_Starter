# FIRE STARTER (ファイヤースターター)

> *「君の戦いに勝利はない。ただ、街に火を放ち続けるだけ……」*

アニメ『フリクリ』第2話「ファイスタ」にインスパイアされた、**「思春期の閉塞感と自己破壊衝動のジレンマ」**を体験する非公式・非営利のアートゲーム／ファンメイドWebアプリケーションです。
画面上部の **MODE 切替ボタン** により、原作準拠表現（エンズビル／カンティード）と権利クリアな独立オマージュ表現（アッシュビル／黒き炎の使徒ノクス）をワンタッチで切り替え可能です。

---

## 特徴

1. **クリアが存在しない無限ループのジレンマ**
   - **閉塞度 (SUFFOCATION)**: 放置すると街の建物が自動増殖し、100%に達すると「日常への埋没」でゲームオーバーになります。火をつけている間だけ閉塞度が下がります。
   - **焼失率 (DESTRUCTION)**: 街を燃やしすぎると上昇し、100%に達すると「自己破滅（居場所の喪失）」でゲームオーバーになります。
2. **「チープな4階調反射型液晶」と「夕暮れの河原の現実」の二重構造**
   - 画面中央の携帯ゲーム機（224×144ドット、残像エフェクト付き4階調オリーブLCD）の外側で、河原のせせらぎ、遠くのサイレン、プラスチックボタンを連打する乾いたカチカチ音、そして噂話や孤独な独白が侵食してきます。
3. **外部アセットゼロ（100% プロシージャル生成）**
   - 画像ファイル・音声ファイルを一切使用せず、TypeScript + HTML5 Canvas + Web Audio API のみでグラフィック・環境音・8bit効果音・オルタナティヴロック風の歪んだギターフィードバックをリアルタイム合成しています。

## 操作方法（PCキーボード / マウス / スマホタッチ対応）

| 操作 | PCキーボード | 画面内ボタン（マウス / スマホタッチ） |
| :--- | :--- | :--- |
| **移動** | `矢印キー` または `WASD` | 画面左側の **十字キー (▲▼◀▶)** |
| **着火 (FIRE)** | `Z` または `Space` | 画面右側の **FIRE [A]** ボタン |
| **アイテム切替** | `X` または `Shift` | 画面右側の **WEAPON [B]** ボタン |
| **黒き炎の祈り（顕現）** | `C` または `Enter` | 画面下部の **PRAY [START]** ボタン（※危機時のみ発動可） |

## ローカル起動・ビルド手順

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番用ビルド（dist/ フォルダに出力）
npm run build
```
