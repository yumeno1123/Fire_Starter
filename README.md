# 『フリクリ』Fire Starter（ファイヤースターター）

アニメ『フリクリ（FLCL）』第2話で作中キャラクター（サメジマ・マミ美）が熱中してプレイしていた架空の携帯ゲーム『Fire Starter（ファイヤースターター）』を、スマートフォン端末およびPCブラウザで快適にプレイできるスタンドアロンのPWA（Progressive Web App）として再現・実装したWebゲームです。

---

## 1. ゲームコンセプト・世界観

* **世界観**: プレイヤーは「黒き炎の神 カンティード」の僕（しもべ）となり、無秩序に自律増殖を続ける悪魔の街「エンズビル」を焼き払って世界の浸食を阻止します。
* **基本理念**: 「救済や完全な勝利（ステージクリア）は存在しない」。
  * 街を燃やさなければ増殖に呑まれて**圧殺**され、
  * 燃やし尽くせば自らの居場所を失って**完全消滅**する。
  * 警察官の追走と消防士の消火をかいくぐり、火加減の綱渡りをしながらひたすら火を焚き続けるエンドレス・サバイバルゲームです。

---

## 2. 操作方法

### スマートフォン操作（タッチパネル）
* **仮想十字キー（D-Pad）**: プレイヤーの上下左右移動 / タイトル画面での難易度選択（EASY / NORMAL / HARD）
* **Aボタン**: 炎の設置 / 選択中の火具の使用（着火・投擲） / タイトル画面でのゲーム開始
* **Bボタン**:
  * 短押し: 所持火具の切り替え（マッチ → ジッポー → 火炎瓶 → 時限爆弾）
  * 長押し + 移動: ダッシュ（スタミナを消費して高速移動）
* **STARTボタン**: 一時停止（PAUSE） / 延焼状況マップの確認 / タイトル画面でのゲーム開始
* **SELECTボタン**: カンティード神への「炎の奉納値（スコア）」および所持アイテム確認 / カラーパレット変更
* **MUTEボタン**: BGM・効果音のミュート切替

### PCキーボード操作
* **移動 / 難易度選択**: `矢印キー` または `W / A / S / D`
* **Aボタン（着火/決定）**: `Z` または `Space` または `J`
* **Bボタン（切替/ダッシュ）**: `X` または `Shift` または `K`
* **STARTボタン**: `Enter` または `P`
* **SELECTボタン**: `Tab` または `C`
* **ミュート切替**: `M`

## 3. ゲームシステム・難易度・火具一覧

### 3つの難易度モード（タイトル画面で切替可能）
タイトル画面で十字キー（▲/▼/◀/▶）を押して選択できます。各難易度ごとにハイスコアが個別保存されます：
1. **EASY（かんたん）**: 炎の燃え広がりが穏やかで、建物の耐久性も高く街が全焼しにくい設計。初期弾薬が1.5倍、スタミナ消費が少なく、警察の索敵・追跡も緩やか。街が全滅寸前になると自律再生するセーフティ付き。
2. **NORMAL（ふつう）**: 延焼と自己増殖の絶妙な綱渡りを楽しめる標準バランス。局所的な延焼減衰により、理不尽な全焼を防ぎつつ原作の世界観を体感できます。
3. **HARD（むずかしい）**: 街の自己増殖が猛烈なスピードで加速し、警察官も素早く索敵。初期弾薬がシビアな上級者向けサバイバルモード。

### 街の自己増殖（セル・オートマトン）
* コンクリートと鉄骨の区画は時間経過とともに自律的・無機質に増殖します。
* 放置すると移動可能マスが狭まり、やがて圧殺されます。

### 4種類の火具（アイテム）
街の路地や燃え跡から回収・使用できます：
1. **マッチ（Match）**: 初期装備。足元・前方に即座に着火。延焼速度は穏やか。
2. **ジッポーライター（Lighter）**: 高火力で確実に点火。延焼力・持続力が高い。
3. **火炎瓶（Molotov）**: 3マス先へ放物線を描いて投擲。着弾時に周囲を一気呵成に燃え上がらせる（敵をスタン）。
4. **時限爆弾（Time Bomb）**: 足元に設置後、3秒カウントで5×5の広範囲を爆砕・灰化させ、周囲を着火する（敵を長時間スタン）。

### 妨害AI
* **消防士（Firefighter）**: 火の手が上がると急行し、放水鎮火を行う。消火された地面は再び街の増殖苗床となる。
* **警察官（Police Officer）**: 街を巡回し、視界に入ったプレイヤーを追跡・捕縛する。接触すると現行犯逮捕となる。建物の物陰や煙に紛れて視界を遮ることでやり過ごすことが可能。

### 敗北条件（3大ゲームオーバー）
1. **全焼（完全消滅）**: 街の建物が0棟になったとき（HUDの建物残量が12%以下になると `!BURN!` アラートが点滅）。
2. **圧殺（完全浸食）**: 街の密度が限界を超えたか、プレイヤーが建物に囲まれ身動きが取れなくなったとき。
3. **逮捕**: 警察官に捕縛されたとき。

## 4. 起動手順・動作確認方法

### 方法1: バッチファイルを実行（最も簡単・おすすめ）
フォルダ内の **[`起動.bat`](file:///C:/Users/Owner/Documents/myproject/Fire_Starter/起動.bat)** または **[`start.bat`](file:///C:/Users/Owner/Documents/myproject/Fire_Starter/start.bat)** をダブルクリックするだけです。
自動的にローカルサーバーが立ち上がり、既定のブラウザでゲーム画面が開きます。

### 方法2: Node.jsで手動起動
```bash
# プロジェクト直下で実行
npm start
```
起動後、ブラウザで [http://localhost:8080](http://localhost:8080) を開きます。

### 方法3: Pythonで手動起動
```bash
python -m http.server 8080
```
起動後、ブラウザで [http://localhost:8080](http://localhost:8080) を開きます。

### テスト実行
```bash
npm test
```
街の増殖シミュレーション、延焼判定、警察・消防AI、各ゲームオーバー条件の自動テスト（16項目）が実行されます。

## 5. PWA（Progressive Web App）インストール手順

* **iOS（Safari）**: 画面下部の共有ボタンから「ホーム画面に追加」をタップ。
* **Android（Chrome）**: メニュー（︙）から「アプリをインストール」または「ホーム画面に追加」をタップ。
* ホーム画面のアイコンから起動すると、アドレスバーのない全画面スタンドアロン表示で快適にプレイ可能です。オフラインでも動作します。
